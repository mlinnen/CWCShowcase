# Events

This module is used to manage the available events for competition. Access is restricted to users with the **Event Manager** role.

## 1. Accessing Events
1. From the **Main Menu**, select the **Events** module.
2. Select **Events** from the submenu.

## 2. Managing Events
This screen allows you to define the schedule and registration windows for each competition.

### Form Fields
The following fields are managed for each event:

- **Code**: A short, unique identifier for the event.
- **Long Name**: The full descriptive name of the event.
- **Active (N or Y)**: Determines if the event is currently active in the system.
- **Vendor Registration**:
    - **Start Date**: When vendors can begin registering.
    - **End Date**: The deadline for vendor registration.
    - **Open (N or Y)**: Manual toggle to open/close vendor registration.
- **Competitor Registration**:
    - **Start Date**: When competitors can begin registering.
    - **Early Registration End Date**: The deadline for early bird pricing.
    - **Registration End Date**: The final deadline for all competitors.
    - **Open (N or Y)**: Manual toggle to open/close competitor registration.
    - **Early Registration (N or Y)**: Toggle to enable/disable early bird status.
- **Event Schedule**:
    - **Event Start Date**: The first day of the competition.
    - **Event End Date**: The final day of the competition.

### Adding a New Event
1. Click the **Add Icon (+)**.
2. Complete the **Form Fields** as described above.
3. Click the **Save** button.

### Editing an Event
1. Locate the event in the list.
2. Click the **Row** to open the **Detail View**.
3. Click the **Pencil Icon** to open the edit form.
4. Update the fields as needed and click **Save**.

### Deleting an Event
1. Locate the event you wish to remove.
2. Click the **Row** to open the **Detail View**.
3. Select the **Delete** action.
    - *Note: Be cautious when deleting events that have associated competitors or judging results.*
