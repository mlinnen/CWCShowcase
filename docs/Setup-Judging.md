# Setup Judging

This module is used to configure the judging assignments for the event. Access is restricted to users with the **Admin** or **Judging Manager** roles.

## 1. Accessing Setup Judging
1. From the **Main Menu**, select the **Judging** module.
2. Select **Setup Judging** from the submenu.

## 2. Managing Judging Entries
This screen allows you to define which categories and styles are ready for judging and which teams are assigned to them.

### Adding a New Entry
1. Click the **Add Icon (+)**.
2. **Category**: Select the category from the dropdown. You can search for a category within the field or clear the selection if needed.
3. **Division/Style**: Select the specific competition area to be judged.
4. **Assigned Team**: Assign a specific judging team (e.g., Team 1, Team 2) to this entry.
5. **Save**: Click the **Save** button to add the entry to the list.

### Editing an Entry
1. Locate the entry in the list.
2. Click the **Row** to open the **Detail View**.
3. Click the **Pencil Icon** to open the edit form.
4. Update the following fields as needed:
    - **Category**: Select the category from the dropdown. You can search for a category or clear the current selection.
    - **Division**: Select a level (**Novice**, **Intermediate**, or **Open**) using the radio buttons.
    - **Style**: Select the style (**N** or **P**) using the radio buttons.
    - **Team**: Reassign the judging team.
    - **1st Place Prize**: The prize amount or description for 1st place.
    - **2nd Place Prize**: The prize amount or description for 2nd place.
    - **3rd Place Prize**: The prize amount or description for 3rd place.
5. Click **Save** to commit changes.

### Deleting an Entry
1. Locate the entry you wish to remove.
2. Click the **Detail View** (by clicking the row) and select **Delete**, or use the delete action if available on the list.
3. *Note: Deleting a setup entry will remove the associated judging record. Use with caution.*

## 3. Common Operations
- **Search**: Use the search bar at the top to find specific categories or teams.
- **Copy**: Use the **Copy Icon** to quickly duplicate a setup entry for a different style or team.
- **Cancel**: Use the **Cancel** button to exit any form without saving changes. No confirmation prompt will be displayed.
